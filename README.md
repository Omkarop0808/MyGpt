## 🆘 Troubleshooting

### Backend won't start?
```bash
# Check MongoDB is running
net start MongoDB

# Check port 3000 is free
netstat -ano | findstr :3000
```

### Frontend won't start?
```bash
# Reinstall modules
cd frontend
rm -rf node_modules
npm install
npm run dev
```

### CORS errors?
```
Check CLIENT_ORIGIN in backend/.env
Should be: http://localhost:5173
```
